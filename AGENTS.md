# AGENTS.md — карта для AI-агентов

Человеку сюда читать не обязательно: точка входа для людей — [README.md](README.md).

## Что это

`dev>nulll music` — song-request бот для Twitch: зритель тратит баллы канала на
награду, бот находит трек, качает на VPS, ставит в очередь и отдаёт аудиопоток в
OBS. Go-сервис + liquidsoap в Docker + yt-dlp + nginx/cloudflared.

## Что читать и в каком порядке

1. [docs/PITFALLS.md](docs/PITFALLS.md) — **до кода.** Всё, что уже стреляло, и
   всё, что выстрелит.
2. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — тракт звука, путь заказа,
   карта кодовой базы по файлам.
3. [docs/OPERATIONS.md](docs/OPERATIONS.md) — деплой, рестарты, диагностика, что
   делать в прямом эфире.
4. [docs/PUBLIC-RELEASE.md](docs/PUBLIC-RELEASE.md) — условия, при которых
   репозиторий можно будет открыть. Сейчас приватный.

## Правила проекта

- **Истина по коду — локальная копия.** На VPS исходники отстают: сверка 15.08
  показала 7 расходящихся файлов, `service/leaderboard.go` есть только локально,
  фикс `player_client`/`extractor-args` — тоже. Бинарь на сервере при этом
  собран из свежих исходников и работает.
- **Деплой — `rsync` + сборка Go на сервере.** Не `git pull`: репозиторий
  заведён 15.08 как хранилище истории, способ доставки он не менял. Порядок —
  в `docs/OPERATIONS.md` (бинарь под нагрузкой не перезаписать, ETXTBSY).
- **Секреты не коммитить.** `librespot/state.json` — настоящие учётные данные
  Spotify, `nginx-dev-nulll.bak` — боевые секретные префиксы путей. Оба в
  `.gitignore` и в истории отсутствуют. Проверять перед каждым `git add -A`.
- **Звук Spotify закрыт экспериментом** (DRM PlayPlay) — не переоткрывать.
- Панель, OAuth-возврат и OBS-док живут под секретным префиксом без `auth_basic`
  намеренно: Twitch и OBS не умеют показывать форму логина.

## Чего не делать
