# dev&gt;nulll music

Song-request бот для Twitch: зритель тратит **баллы канала** на награду «Заказать трек»,
бот находит трек, скачивает его на VPS, ставит в очередь и **отдаёт готовый аудиопоток в
OBS**. Если заказ не удался — баллы возвращаются автоматически, с причиной в чате.

Написан как замена Trula Music, у которой заказчика (стример **f1pah**, Сидней) не
устраивала цензура каталога. Работает пока для одного канала.

- **Стек:** Go 1.26 (сервис) + liquidsoap 2.3.3 в Docker (звук) + yt-dlp (источники) + nginx/cloudflared (веб).
- **Хост:** Frankfurt-стенд `187.124.187.72`, каталог `/root/twitch-music`.
- **Публичная дверь:** `https://get.dev-nulll.com/<WEB_PREFIX>/…` (панель, OAuth, док).
- **Звук:** `http://<user>:<pass>@187.124.187.72:8000/<mount>` — прямой порт, мимо Cloudflare.

## Раскладка

```
twitch-music/
├── service/           # Go-сервис (единственный бинарь tm-service), ~2.5k строк
├── tools/             # разовые исследовательские скрипты (coverage_check.py)
├── deploy/            # снимки инфраструктуры с VPS: compose, radio.liq, unit, nginx, .env.example
└── docs/              # эта документация
```

На VPS в `/root/twitch-music` к этому добавляются **не хранимые в исходниках** вещи:
`.env` (секреты), `secrets/` (токены Twitch + куки YouTube), `cache/` (скачанные треки),
`logs/`, `run/spotify.fifo`, `settings.json` и собранный бинарь `tm-service`.

## Правило работы с исходниками

⚠️ **Истина по коду — локальная копия `~/Desktop/twitch-music/`; на VPS исходники не
правим.** Код катается на сервер `rsync`'ом, там только собирается и запускается.
Сделано сознательно (в отличие от прошлого проекта ai-manhunt), чтобы не заводить дрейф
между машинами. Обратное направление тоже бывает нужно — см.
[грабли про `go.mod`](docs/PITFALLS.md#синхронизация-и-сборка).

## Что бот умеет

**Зрителю** — награда за баллы (ссылка YouTube/SoundCloud/Spotify или просто название),
`!song` / `!np` / `!трек`, `!queue` / `!очередь`, `!help`.
**Модератору и стримеру** — `!skip`, `!sr <ссылка/название>` в чате плюс веб-панель:
очередь с перестановкой и удалением, пауза/скип, две независимые громкости (эфир и
наушники стримера), включение награды и её цена, лимит длины трека.
**Стримеру в OBS** — `Custom Browser Dock` со «сейчас играет», обложкой, очередью и
громкостью, вход по ключу в ссылке.

## Границы, принятые осознанно

- **Фильтров и цензуры нет.** Статус канала — Affiliate, риск по DMCA принят заказчиком.
- **Spotify играть нельзя** — только каталог/поиск. Их DRM (PlayPlay) закрыл сторонним
  клиентам доступ к ключам; проверено экспериментом, [не переоткрывать](docs/PITFALLS.md#spotify).
- **Альбомы и плейлисты отклоняются** — одна активация награды не должна забивать эфир на час.
- **Мульти-тенант не заложен**: канал, награда и токены — в единственном экземпляре.
